
# 乐刷收银通商户入网次数超限报备指引

本指引旨在说明当商户因同一法人身份证或营业执照入网次数达到上限时，如何申请提高入网次数限制。

## 一、入网次数限制规则

*   **有营业执照商户**：同一营业执照最多可入网30次。若法人身份证与营业执照法人一致，该身份证也可入网30次。
*   **无营业执照商户（小微商户）**：同一身份证最多可入网10次。
*   **特殊场景**：对于总分店、连锁品牌等特殊场景，可向乐刷申请报备，审核通过后可进行个性化调整。
*   **小微商户限制**：小微商户暂不允许申请增加入网次数，如有特殊场景需联系运营并描述具体情况。

## 二、申请资料清单

### 基础资料
1.  **营业执照**：原件拍照，如为复印件需加盖公章。
2.  **法人身份证**：正反面原件拍照，如为复印件需加盖公章。
3.  **经营信息确认书**：需按要求填写完整，公司加盖公章，个人需签名并按手印，确保清晰可见。

### 不同入网场景的补充资料

| 入网场景 | 需补充提供的资料 |
| :--- | :--- |
| **品牌连锁商户** | 1. 统一运营管理场景说明（如为小程序，提供截图）。2. 若营业执照非品牌总部，提供总部统一经营授权函。3. 若为加盟店，提供加盟协议；若无法提供，则需提供加盖公章的门店清单及视频（50次以内提供3家，50-100次提供5家，超过100次必须提供加盟协议）。 |
| **美食城、市集、夜市、商业街** | 1. 场地租赁合同或不动产权证明。2. 商户与实际经营方签订的合作协议。3. 现场场地视频。 |
| **员工餐厅、学校食堂** | 1. 与公司或高校签订的承包合同（如无法提供，需说明情况或提供辅助资料）。2. 完整的食堂视频（从门头到内部所有档口）。 |
| **当地生鲜超市档口** | 1. 提供实际门店名称、地址、数量及各店档口数。2. 各门店视频（含门头、营业执照悬挂处、经营规模），若门店超6个，可先提供6家。 |
| **停车场** | 1. **公共停车场**：提供商户与国家管理局签订的经营权出让合同。2. **自建车场**：提供土地所有权证明、车场地址分布情况表。3. **物业管理类车场**：提供与物业或居委会签订的场地使用合同、车场分布情况图。 |
| **商城、商业广场** | 1. 商城管理方与店铺间签署的合同（或能证明合作关系的盖章页）。2. 每个店铺的名称、地址清单。 |
| **非品牌连锁商户（个人多家商铺）** | 1. 一般增加次数不超过10次。2. 提供5家商铺的经营场所视频。3. 提供每一家店铺的名称及地址清单（需加盖商户公章）。 |

## 三、申请流程

1.  **准备资料**：按要求准备好所有申请资料。
2.  **发送邮件**：将资料整理后，通过邮件发送至 `syt@yeahka.com`。
3.  **等待审核**：乐刷收到邮件后会进行审核。
4.  **接收结果**：审核通过后，乐刷会调整入网次数上限，并通过邮件回复告知处理结果。

## 四、邮件申请内容规范

### 邮件标题格式
`代理商名称（代理商编号）+商户入网次数报备+日期`

### 邮件正文模板
*   **代理商名称（代理商编号）**：xxxxx公司（38xxx67）
*   **营业执照名称（编号）**：xxx有限公司，916xxxx1234
*   **法人身份证名称（号码）**：张三，123456xxxx7891
*   **入网次数**：50（按实际业务需要申请，若后续会增加门店请加上预估门店数）
*   **结算模式描述**：
    *   **法人结算**：申请入网的\*\*\*\*家商户统一结算到法人账户。
    *   **非法人结算**：需说明结算人与营业执照法人之间关系，为何使用此结算模式？
*   **入网场景描述**：（详细描述商户具体使用场景）
    *   **注**：统一运营管理的场景如为小程序，请提供小程序相关截图；若为其他原因请说明清楚。
*   **附件资料**：
    *   【营业执照照片】
    *   【法人身份证正反面】
    *   【经营信息确认书与统一授权函模板】

## 五、测试商户提高入网次数申请

### 邮件发送规范
*   **邮件主题**：`代理商名称【代理商编号】测试用身份证提高入网次数上限申请`
*   **收件人**：对接运营邮箱
*   **抄送**：`syt@yeahka.com`

### 邮件正文模板
*   **申请事由**：因测试xxxx（尽可能详细的测试需求内容）等功能，现有证件入网次数无法满足测试需求，现申请将此身份证入网次数提高至xx次，测试时长为xx（6个月为上限）。
*   **代理商名称**：xxxx公司
*   **代理商编号**：1234567
*   **姓名**：张三
*   **身份证号**：123456\*\*\*\*\*\*\*\*7890
*   **营业执照编号**：123456\*\*\*\*\*\*\*\*\*（如无则不填）
*   **照片内容**：
    1.  营业执照照片（如无则不填）
    2.  法人身份证正反面
    3.  测试员工证明内容（此处放证明此人为公司测试人员的证明如手持工牌照等，需清晰可见本人与公司关系内容；如员工非营业执照主体法人，则需描述测试员工与主体关系）

### 注意事项
1.  邮件发送后乐刷侧会进行审核，审核通过后会告知代理商处理结果。
2.  代理商需定期整理不再使用的测试商户提供给乐刷运营以便注销此类商户。小微商户注销条件为30天内无交易。
3.  使用此证件进件的测试商户需在简称中加入“测试”二字。
4.  如果营业执照非代理商入网主体，则需描述营业执照主体与代理商入网主体关系。
5.  禁止使用真实商户资料提升测试用入网次数。

## 六、常见问题解答

### 问：小微商户支持增加入网次数吗？
**答**：小微商户暂不允许申请增加入网次数，如有特殊场景请联系运营并描述具体场景。
