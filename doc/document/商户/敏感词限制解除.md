
# 敏感词限制解除申请指引

本指引旨在说明当商户因营业执照名称或商户简称命中敏感词导致入网被拦截时，如何申请解除限制。

## 一、背景

因商户营业执照名称或商户简称命中了我司的敏感词限制，会在入网提交资料时被拦截，需要提供排查资料进一步核实解除敏感词。

## 二、资料要求

### 小微商户入网简称敏感词（禁止使用）

以下词汇禁止在小微商户的简称中使用：
*   企业、集团、货车、车行、租车、车贷、汽车租赁、二手车、汽车
*   黄金、珠宝
*   旅行社、棋牌、殡仪
*   彩票、体彩
*   中心、玉石、银行

### 营业执照入网商户敏感词

对于使用营业执照入网的商户，若名称包含以下敏感词，需提供相应资料：

| 敏感词 | 需提供的资料 |
| :--- | :--- |
| 寄售、寄售行、寄卖、寄卖行、典当 | 1. 商户巡检视频2. 代理商风险担保函 |
| 保险 | 1. 商户巡检视频2. 保险经营许可证 |
| 基金、投融资 | 1. 商户巡检视频2. 相关交易合同3. 经营许可证 |
| 其他情况 | 提供商户巡检视频，视频需拍摄到店内三合照场景和营业执照清晰信息 |

## 三、邮件申请解除流程

### 邮件发送规范

1.  **邮件主题**：`代理商编号+代理商名称+申请解除进件敏感词+日期`
2.  **收件邮箱**：`syt@yeahka.com`；`support2@yeahka.com`
3.  **邮件内容**：
    *   商户号：1234567890
    *   商户名称：XXXXX
    *   申请解除敏感词，请处理；
4.  **附件**：
    *   风险担保函--入网报备.pdf (根据要求填写)

### 风险担保函

需使用乐刷提供的《风险担保函--入网报备》模板，按要求填写完整并加盖公章。
