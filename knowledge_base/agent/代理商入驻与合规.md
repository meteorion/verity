# 乐刷收银通代理商入驻与合规操作指引

本指引整合了乐刷收银通代理商从入网签约、下级代理拓展、层级申请、主体变更到合规备案及费率配置的全流程操作规范，适用于**一级代理商**（简称**一代**）及下级代理商的日常运营与合规管理。

## 代理商入网流程

成为乐刷收银通一级代理商的完整入网流程包括三个核心步骤：**签署合作协议**、**线上填写入网申请**、**完成收单外包机构备案**。

### 代理商入网签约方式

| 签约类型 | 是否需要签约 | 签约方式 |
| :--- | :--- | :--- |
| 服务商签约 | 是 | 线下与乐刷完成纸质签约 |
| 商户接入签约 | 是 | 电子签约 |

合作意向确认后，服务商可联系乐刷商务获取协议模板——《移动支付服务协议》及《移动支付服务协议费率补充协议》。

### 代理商入网签约费率与政策约定

1.  服务商与乐刷BD（业务拓展经理）约定**签约费率**。
2.  双方谈妥**参与政策**后，乐刷BD发送签约协议模板电子版。

### 代理商入网合同填写与邮寄规范

1.  **填写合同及盖章**：合同模板及填写规范详见[合同模板及填写规范](https://www.yuque.com/sweden/xqglkl/roobrv1nv92iyxwp)。
2.  **提供扫描件**：填写完合同，加盖**公章**和**骑缝章**后，先发协议扫描件给乐刷商务，让其确认合同是否有问题。
3.  **纸质合同邮寄**：乐刷商务确定合同无问题后，告知BD合同回寄地址。合同一式三份，邮寄到乐刷总部。

1.  通过销售BD同事提供的**专属链接**（BD会提前对意向服务商进行初步信息登记，登记后生成专属链接）进行资料填写。
2.  **电子邮箱**处需填写真实邮箱，代理商入网后，乐刷会每日自动发送代理商下属商户的昨日所有交易明细及所有流水明细。目前此处只能填写一个邮箱，若需要把报表发送到更多邮箱，或后期修改接收邮箱，请在对接群中联系收银通运营。
3.  **结算信息**目前只支持对公结算，此对公账户为后续每月**分润打款帐号**。

### 代理商入网申请关键注意事项

- 代理商入网申请中的**代理商帐号**及**登录密码**为后续登录收银通后台凭证，需牢记。
- 如遗忘密码，可凭当时绑定的手机号码找回。
- 一般情况下，合作协议寄给乐刷后 **1-2周** 会安排回寄。
- 收到回寄的双方盖章协议后，代理商必须完成**收单外包机构备案**。

## 代理商收单外包机构备案流程

本节指导与乐刷合作的外包机构（代理商）完成在中国支付清算协会的备案流程，包括所需资料、申请步骤及关键注意事项。

### 收单外包机构备案申请资格与限制

- 被列入**支付清算协会黑名单**的外包机构，不予受理备案申请。
- **近三年内**备案审核不合格的外包机构，不予受理再次备案申请。

### 外包机构备案申请适用范围与基本条件

**适用范围**：

- 适用于中国境内所有与乐刷有存量或新增合作的服务商。
- 备案发起主体应为**独立法人**（服务商总公司），其分支机构无须单独备案。
- 母子公司关系的，需**分别进行备案**。

**基本条件**（须同时符合）：

- 持有市场监督管理部门核准的营业执照，机构名称、经营场地等应与证照资料一致。
- 有良好的商业信誉，经营状况良好，无重大违法违规记录。
- 机构及其法定代表人/负责人不在监管机构或协会认定的**黑名单**内。
- 遵守监管规定和协会自律管理要求。

**特殊要求**：申请"聚合支付技术服务"的机构，还需建立完善的客户信息安全管理制度和技术保障体系，相关业务系统应符合国家金融行业标准。

| 审核时效 | 协会将于 **20个工作日内** 完成审核（特殊情况最长不超过60个工作日） |

## 下级代理商入网流程

本节说明通过展业APP邀请下级代理商入网的完整流程，包括所需资料、操作步骤及后续信息确认。

### 下级代理商入网前资料准备清单

在发起入网邀请前，上级代理商需确保已获取下级代理商的以下信息：

- **法人身份证正反面照片**
- **公司经营地址**（展业地址）
- **法人手机号**

### 上级代理商发起注册邀请流程

上级代理商登录展业APP，生成专属的入网邀请二维码。

| 项目 | 内容 |
| :--- | :--- |
| 操作路径 | 展业APP -> 我的 -> 代理商管理 -> 邀请下级代理商 |
| 操作说明 | 输入下级代理商法人的手机号，点击生成专属邀请码 |

### 下级代理商扫码注册流程

下级代理商法人使用微信等工具扫描上级提供的邀请码，进入注册页面：

1.  输入**登录账号**（6-12位数字加字母组合，用于后续登录APP）。
2.  输入法人本人手机号并获取验证码。
3.  点击"确认注册"。
4.  注册成功后，**初始密码**将通过短信发送至法人手机。

### 下级代理商实名认证流程

下级代理商法人使用收到的账号密码登录展业APP，完成实名认证和人脸识别。

| 项目 | 内容 |
| :--- | :--- |
| 操作路径 | 登录APP -> 点击"去实名认证" -> 提交法人信息（身份证照片、手机号、经营地址） -> 完成人脸识别认证 -> 提交乐刷审核 |
| 审核时效 | 系统审核通常需要 **10个工作日**，请耐心等待 |

### 上级代理商确认成本信息流程

乐刷审核通过后，上级代理商需登录展业APP，为下级代理商配置并确认成本信息。

| 项目 | 内容 |
| :--- | :--- |
| 操作路径 | 展业APP -> 我的 -> 代理商管理 -> 下级代理商查询 -> 找到"审核通过"的代理商 -> 点击"修改成本" -> "信息确认" |

成本信息确认无误后，下级代理商即可正常展业。

### 下级代理商入网资料查看与修改规则

| 项目 | 内容 |
| :--- | :--- |
| 操作路径 | 展业APP -> 我的 -> 已实名 -> 入网资料 |
| 修改说明 | 修改资料时需进行法人人脸识别认证 |

## 代理商主体变更流程

代理商在发生主体信息变更时，需根据变更类型选择对应的处理流程。主要包括三种场景：**营业执照编号已变更**、**营业执照编号未变更**、**仅修改对公账户信息**。

### 代理商营业执照编号已变更的主体变更前置条件

此流程适用于代理商的**社会统一信用代码**（即营业执照编号）发生变更的情况。

- 在发起变更前，请确认旧主体与乐刷签订的《收单外包合作协议》仍在 **两年有效期**内。
- 例如，若代理在2025年4月1日发起变更，则旧主体协议的签订日期不得早于2023年4月1日。
- 若协议已过期，需先与乐刷**续签协议**。

### 代理商营业执照编号已变更的协议签署要求

1.  签署《权利义务转让协议》一式叁份，需加盖**公章**和**骑缝章**。
2.  用新主体重新签署合同一式叁份，需加盖**公章**和**骑缝章**。
3.  **注意**：除旧主体协议外，所有新签署的协议日期暂时空着不填。

**文件规格要求**：

- PDF协议文件：不大于 **5MB**。
- 证件信息图片：不大于 **1MB**。

### 代理商营业执照编号已变更的所需资料清单

1.  《权利义务转让协议》的照片或扫描件。
2.  新主体签署合同的照片或扫描件。
3.  旧合同的照片或扫描件（必须为**原件拍摄**）。
4.  新营业执照原件照片或扫描件（如为复印件请加盖公章）。
5.  新开户许可证原件照片或扫描件（如为复印件请加盖公章）。
6.  新法人身份证正反面照片原件照片或扫描件（如为复印件请加盖公章）。

## 代理端商户费率成本模板配置流程

本节指导代理商如何在展业APP中配置并使用商户费率成本模板。

### 代理端新增成本模板操作路径

1.  打开**代理商展业APP**。
2.  进入"**我的**"页面。
3.  点击"**成本模板**"选项。
4.  选择"**新增模板**"进行创建。

### 商户应用费率模板操作路径

1.  在**代理商展业APP**中，进入"**查询**"页面。
2.  点击"**自有商户**"，选择需要操作的商户。
3.  进入"**商户信息**"详情页。
4.  点击"**商户费率**"。
5.  在页面右上角点击"**使用模板**"。
6.  勾选已配置好的模板，点击"**导入保存**"即可。

## 代理商入驻与合规常见问题

### 问：代理商入网申请中的对公账户有什么作用？

答：代理商入网申请中的对公账户有两个核心作用：一是用于代理商收银通业务的资金结算；二是作为后续**每月分润打款账号**。结算信息目前只支持对公结算。

### 问：代理商入网后忘记登录密码怎么办？

答：代理商入网申请中的代理商帐号及登录密码为后续登录收银通后台凭证，如遗忘可凭当时绑定的**手机号码**找回密码。

### 问：下级代理商实名认证需要多久？

答：下级代理商提交实名认证后，系统审核通常需要 **10个工作日**，请耐心等待。

### 问：一代代理商是否支持修改入网资料？

答：**一代代理商**仅支持查看入网资料，**不支持修改**。其他层级代理商修改资料时需进行法人人脸识别认证。

### 问：备案有效期是多久？到期后如何处理？

答：备案有效期为 **2年**。外包机构须在到期日前提前 **90个自然日** 重新提交备案申请。

### 问：备案到期未处理会有什么后果？

答：备案到期后5个工作日内如未提交异议，则备案将被取消，且 **3年内** 不能再提交备案申请。

### 问：被协会强制取消备案后还能再次申请吗？

答：被强制取消备案的外包服务机构，**3年内** 不能再提交备案申请。同时，该机构的法人及关键人员也不得以其他公司名义再次进行备案申请。

### 问：备案地区范围可以填写"全国"吗？

答：若备案地区范围填写"全国"，则需在每个省份均有分公司。若无分公司，只能填写所在省份及其分公司驻点省份，否则不受理盖章申请。

### 问：代理商主体变更处理的时效是多久？

答：申请提交后，预计在 **7个工作日内** 处理完毕，处理完成后会通过邮件回复通知。如有疑问，请通过企业微信沟通。
