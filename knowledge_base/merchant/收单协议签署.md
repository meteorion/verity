
# 商户收单协议签署方式及流程

本指引旨在说明商户如何通过“收银通APP”完成《特约商户支付服务合作协议》的签署。未签署协议的商户，其交易额度或交易功能可能会受到影响。

## 一、签署路径

商户可通过以下两种路径进入协议签署页面：
1.  **弹窗签署**：登录“收银通APP”后，若协议未签署，系统会自动弹出签署提醒。
2.  **手动进入**：登录“收银通APP” → 我的 → 商户信息 → 签约费率 → 特约商户支付合作协议 → 续签。

## 二、小微及个体工商户签署流程

1.  **进入签署**：点击弹窗中的“去签署”或在“签约费率”页面点击“去签约”。
2.  **浏览协议**：进入协议浏览页面，仔细阅读协议内容。
3.  **手写签名**：
    *   点击页面下方的签名处，进入“手写签名”页面。
    *   根据提示，将手机横屏，在签名区使用正楷字体书写姓名。
    *   可点击“撤销重签”清空已写签名。
4.  **签名检测**：
    *   签名完成后，系统会自动进行签名检测。
    *   若检测不通过，需重新签署。
    *   若检测通过，点击“签署完成”按钮。
5.  **签署成功**：页面提示“签署成功”，即完成协议签署。

## 三、企业商户签署流程

企业商户的签署流程更为严格，需经过法人授权和人脸识别认证。

### 1. 选择管理员身份

登录APP后，需选择本次发起签署的管理员身份：
*   **企业法定代表人**
*   **企业授权代理人**

### 2. 企业认证

根据选择的管理员身份，进行相应的认证操作：

*   **若选择“企业法定代表人”**：
    1.  上传营业执照并填写企业信息。
    2.  认证方式选择“法人身份认证”。
    3.  系统将向法人手机号发送授权协议，法人需同意并进行人脸识别。

*   **若选择“企业授权代理人”**：
    1.  上传营业执照并填写企业信息。
    2.  认证方式选择“法人授权认证”。
    3.  输入法人手机号，系统将向法人手机号发送授权协议，法人需同意并进行人脸识别。

**特别注意**：目前仅支持持有中国大陆居民身份证的法人代表进行授权认证。

### 3. 协议签署

1.  法人完成人脸识别认证后，会通过短信接收到一份授权协议。
2.  法人根据短信指引，输入验证码完成协议签署。
3.  页面提示“签章成功”，即表示企业商户协议签署完成。
