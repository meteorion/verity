
# 乐刷收银通商户入网操作流程

本文档旨在指导代理商通过“收银通展业版APP”完成商户入网（进件）的全流程操作。

## 一、创建商户账户

1.  **登录应用**：代理商登录“收银通展业版APP”，进入“首页”，点击“商户入网”。
2.  **开始进件**：在商户入网页面，点击“进件商户”。
3.  **填写基础信息**：
    *   输入商户的“手机号”与“登录名”。
    *   **登录名建议**：建议使用手机号。若提示被占用，可使用其他数字组合，但需确保商户能够记住。
4.  **进入下一步**：信息填写完毕后，点击“下一步”。

## 二、录入商户信息

1.  **设置商户费率**：
    *   点击“商户费率”，如需修改，点击“修改”按钮进行调整。
    *   修改完成后，点击左上角返回箭头。
2.  **完善身份资料**：
    *   点击完善“身份资料”。
    *   选择需要进件的商户类型。
    *   按要求上传商户法人身份证正反面照片。
    *   填写商户的“门店资料”。
    *   **特别提示**：若营业执照名称为空或为 `*`，则全称统一填写为法人姓名，不再支持填写“个体户+姓名”。
    *   **执照上传**：如有营业执照的商户，需上传商户营业执照照片。
    *   检查无误后，点击“下一步”。
3.  **配置结算信息**：
    *   选择结算方式，并上传结算人银行卡照片。
    *   **特殊情况**：如选择“打款至他人银行卡”，需额外上传以下文件：
        *   结算人身份证正反面照片。
        *   乐刷结算授权函文件（需按要求填写完整）。
    *   选择银行信息并检查无误后，点击“下一步”。
4.  **上传门店照片**：
    *   上传门店三合照，包括：门头照、收银台照、店内经营照。
    *   上传完毕后，点击“保存”。

## 三、提交审核

1.  **确认并提交**：所有资料填写上传并确认无误后，点击“提交审核”，在弹窗中再次点击“提交”。
2.  **等待审核**：
    *   页面提示“资料审核中，请等待...”。
    *   **审核时长**：一般资料信息无误的情况下，等待几分钟即可。若选择“打款至其他人”，审核时间约为30分钟。
3.  **审核结果**：审核通过后，商户进件成功，即可开始进行“微信认证和支付宝认证”等后续操作。
