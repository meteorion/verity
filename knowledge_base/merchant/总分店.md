
# 乐刷收银通开设分店操作指引

本指引旨在指导代理商通过“收银通展业版APP”为已入网的商户开设分店（子门店）的完整流程。

## 一、新增门店流程

1.  **登录应用**：代理商登录“收银通展业版APP”，点击“查询”，在“自有商户”列表中找到需要开设分店的商户。
2.  **进入门店列表**：点击该商户，进入详情页后，点击“门店列表”。
3.  **新增门店**：在门店列表页面，点击“新增门店”。
4.  **总店授权**：点击“下一步”，进行总店授权操作。
5.  **设置分店账户**：
    *   设置“分店联系手机”。
    *   设置“分店登录名”。
    *   设置“分店登录密码”。
    *   设置完成并检查无误后，点击“下一步”。
6.  **选择资料模式**：根据分店实际情况，选择“门店资料与总店是否一致”。

## 二、门店资料与总店一致

当选择“门店资料与总店一致”时，请按以下步骤操作：

1.  **选择一致**：点击“一致”选项。
2.  **填写分店信息**：
    *   填写分店“门店名称”。
    *   填写分店“店长姓名”。
3.  **设置分店费率**：
    *   填写完门店信息后，点击“费率信息”。
    *   点击“修改”，可对各支付方式的费率进行调整。
    *   费率修改完成后，点击“返回”。
4.  **上传资料并提交**：
    *   按要求上传分店门店的详细资料照片。
    *   选择分店所属区域。
    *   输入分店详细地址。
    *   所有资料上传完毕并确认无误后，点击“提交审核”。
5.  **审核结果**：
    *   审核通常需要几分钟时间。
    *   审核通过后，在“门店列表”页面，分店状态会提示“商户审核通过”。
    *   在“查询”页面的“自有商户”列表中，也会出现该分店的信息。
