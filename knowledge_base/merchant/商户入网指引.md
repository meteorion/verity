# 乐刷收银通商户入网指引

本指引整合了乐刷收银通商户入网的全部规范、操作流程、特殊场景处理及常见问题，适用于代理商通过"收银通展业版APP"完成商户入网（进件）及后续认证操作。

## 商户入网前置规范

### 商户入网禁止地区与主体限制

- **禁止入网地区**：西藏自治区。
- **已注册为一级代理商的营业执照**：不得再作为特约商户提交入网申请。
- **已入网成功的乐刷商户**：其营业执照不可再用于申请一级代理商资格。

### 商户入网行业限制与特殊要求

- **禁入行业**：房地产、保险、投资、融资、投融资、广告、棋牌类、基金、理财、套现、信用卡、传销等。
- **结算限制**：新疆地区不支持企业非法人对私结算。

| 行业类型 | 入网要求 | 特别说明 |
| :--- | :--- | :--- |
| **黄金珠宝行业** | 需营业执照入网且对公结算，经营范围须包含黄金、珠宝等 | 若非对公结算，默认关闭T0结算权限，并需提供包含法人、业务员、门店环境、终端SN码及实时定位的经营场景视频 |
| **汽车行业**（含汽车销售、二手车、租赁、车贷等） | 仅支持个体户或企业商户入网，不支持小微商户 | 福建地区商户需额外上传对应许可证，并在入网后提交实地巡检视频 |
| **投资行业** | 除营业执照外，还需提供经营许可证 | - |

### 小微商户入网特别规定

- **名称规范**：小微商户的法定名称不应设为"广场"、"中心"、"KTV"、"酒店"、"商场"等与实际经营资质不符的名称。
- **MCC规范**：小微商户入网的MCC不应为"住宅开发"、"铁路货运"、"烟草配送"、"公共事业"等与实际经营资质不符的类别。
- **禁入行业**：小微商户不支持"珠宝黄金"、"汽车销售"、"二手车销售"、"汽车租赁"、"车贷"、"车行"、"货车"、"房地产"、"保险"、"投资"、"融资"、"投融资"、"旅行社"、"养老"、"殡仪"、"公司"、"玉石"、"棋牌室"等行业入网。

### 商户入网图片资料提交通用规范

#### 身份证图片提交规范

1. 必须为真实拍摄的原件照片，禁止隔屏拍摄、截图或PS。
2. 照片需露出身份证四个角，信息清晰无反光。
3. 身份证正反面照片的拍摄背景需一致。
4. 身份证超过有效期或即将在1个月内过期的，不能入网。
5. 如上传复印件，需加盖公章，且公章不能遮挡关键信息。

#### 营业执照图片提交规范

1. 必须为真实拍摄的照片，禁止截图、PS或含有水印。
2. 照片需露出营业执照四个角。
3. 如上传复印件，需加盖公章，无公章视为无效。
4. **小微商户无需上传营业执照图片，切勿用其他图片代替。**

#### 店铺环境图片（三合照）提交规范

1. 必须为真实线下场景拍摄，禁止使用网图、PS、截图或含有水印、边框。
2. 必须上传门头照、店内照、收银台照三张不同照片（停车场除外）。
3. 连锁店需上传本店三合照，不可重复使用其他店铺的照片。
4. 无实体店铺的流动摊位，可拍摄体现门店招牌、经营内容、收银场景的照片。

#### 银行卡图片提交规范

1. 必须为真实拍摄的银行卡照片，禁止截图、PS或含有水印。
2. 照片需露出银行卡四个角。
3. **对公结算**：上传开户许可证或银行印鉴卡。
4. **对私结算**：上传有卡号一面的银行卡照片。若卡号磨损，可将卡号写在纸上与银行卡一同拍摄。
5. **三要素鉴权失败处理**（4选1）：
   - 核实并修改结算卡信息。
   - 更换一张结算卡。
   - 上传近一周的转账成功截图（体现开户名和卡号）至其他资料栏。
   - 上传银行提供的商户流水（体现开户名和卡号）至其他资料栏。

#### 非法人结算授权书规范

1. 使用乐刷提供的《结算账户确认书》模板。
2. 按要求填写完整信息，包括商户名称、法人信息、被授权人信息等。
3. 企业需加盖公章，并由法人代表/授权人签字和按手印。
4. 个体工商户由经营者签字和按手印。
5. 将法人身份证原件照片按格式放置在授权书上拍照上传。

## 商户入网操作流程

### 商户入网创建商户账户流程

1. **登录应用**：代理商登录"收银通展业版APP"，进入"首页"，点击"商户入网"。
2. **开始进件**：在商户入网页面，点击"进件商户"。
3. **填写基础信息**：
   - 输入商户的"手机号"与"登录名"。
   - **登录名建议**：建议使用手机号。若提示被占用，可使用其他数字组合，但需确保商户能够记住。
4. **进入下一步**：信息填写完毕后，点击"下一步"。

### 商户入网录入商户信息流程

1. **设置商户费率**：
   - 点击"商户费率"，如需修改，点击"修改"按钮进行调整。
   - 修改完成后，点击左上角返回箭头。
2. **完善身份资料**：
   - 点击完善"身份资料"。
   - 选择需要进件的商户类型。
   - 按要求上传商户法人身份证正反面照片。
   - 填写商户的"门店资料"。
   - **特别提示**：若营业执照名称为空或为 `*`，则全称统一填写为法人姓名，不再支持填写"个体户+姓名"。
   - **执照上传**：如有营业执照的商户，需上传商户营业执照照片。
   - 检查无误后，点击"下一步"。
3. **配置结算信息**：
   - 选择结算方式，并上传结算人银行卡照片。
   - **特殊情况**：如选择"打款至他人银行卡"，需额外上传以下文件：
     - 结算人身份证正反面照片。
     - 乐刷结算授权函文件（需按要求填写完整）。
   - 选择银行信息并检查无误后，点击"下一步"。
4. **上传门店照片**：
   - 上传门店三合照，包括：门头照、收银台照、店内经营照。
   - 上传完毕后，点击"保存"。

### 商户入网提交审核流程

1. **确认并提交**：所有资料填写上传并确认无误后，点击"提交审核"，在弹窗中再次点击"提交"。
2. **等待审核**：
   - 页面提示"资料审核中，请等待..."。
   - **审核时长**：一般资料信息无误的情况下，等待几分钟即可。若选择"打款至其他人"，审核时间约为30分钟。
3. **审核结果**：审核通过后，商户进件成功，即可开始进行"微信认证和支付宝认证"等后续操作。

## 商户入网特殊场景进件规范

### 停车场商户进件规范

- **商户简称**：必须包含"停车场"或有停车含义的字眼。
- **三合照**：拍摄需包含停车杆和车场照片。

### 食堂餐厅商户进件规范

- **资料复用**：同一个食堂的多个档口可使用同一套营业执照和三合照进件。
- **门头照**：拍摄连排档口照片。
- **商户简称**：可使用主体执照名称或各档口实际名称（如"xx学校食堂档口1"）。

### 酒吧商户进件规范

- 大型酒吧、夜场等，允许同一证件使用同套资料注册多个商户编号，三合照需能体现是大型酒吧或夜场。

### 出租车商户进件规范

- **商户简称**：使用车牌号，不得套用知名品牌名称（如滴滴、神州专车）。
- **三合照**：只需提供一张商户本人与车辆的合影，需清晰看见车头、车牌和商户本人。

### 彩票类商户进件规范

- **小微商户**：在其他图片中上传彩票代销证。商户全称填"商户_XXX"，简称填"体育彩票+门店编号"。
- **个体/企业**：需有对应营业执照，并上传彩票代销证。商户全称填营业执照全称，简称填"体育彩票+门店编号"。
- **注意**：若三合照中包含体彩、福彩标识，必须提供代销证。

## 港澳台等证件入网说明

### 港澳台等证件入网进件标准

- 支持港澳台通行证、香港/澳门/台湾身份证、护照、居住证等法定证件。
- 商户主体必须是在中国大陆注册的个体户或企业，**暂不支持小微商户**。
- 经营地址必须在中国大陆境内。
- 结算类型仅支持对私法人结算或对公法人结算。

### 港澳台等证件入网流程

1. 商户类型选择"个体户"或"企业"。
2. 法人证件类型选择对应的证件（如"港澳台通行证"）。
3. 收款账号填写在中国大陆开立的银行账户。
4. **特别注意**：港澳台通行证入网时，证件号处需填写"证件号码+换证次数"（例如证件号为`123456`，换证次数为`01`，则填写`12345601`）。

### 港澳台等证件入网特别说明

- 使用其他证件类型入网的商户，审核通过后不允许修改法人信息。如需变更，请重新进件。

## 商户入网次数限制与报备

### 商户入网次数限制规则

- **有营业执照商户**：同一营业执照最多可入网30次。若法人身份证与营业执照法人一致，该身份证也可入网30次。
- **无营业执照商户（小微商户）**：同一身份证最多可入网10次。
- **特殊场景**：对于总分店、连锁品牌等特殊场景，可向乐刷申请报备，审核通过后可进行个性化调整。
- **小微商户限制**：小微商户暂不允许申请增加入网次数，如有特殊场景需联系运营并描述具体情况。

### 商户入网次数报备申请资料清单

#### 基础资料

1. **营业执照**：原件拍照，如为复印件需加盖公章。
2. **法人身份证**：正反面原件拍照，如为复印件需加盖公章。
3. **经营信息确认书**：需按要求填写完整，公司加盖公章，个人需签名并按手印，确保清晰可见。

#### 不同入网场景的补充资料

| 入网场景 | 需补充提供的资料 |
| :--- | :--- |
| **品牌连锁商户** | 1. 统一运营管理场景说明（如为小程序，提供截图）。2. 若营业执照非品牌总部，提供总部统一经营授权函。3. 若为加盟店，提供加盟协议；若无法提供，则需提供加盖公章的门店清单及视频（50次以内提供3家，50-100次提供5家，超过100次必须提供加盟协议）。 |
| **美食城、市集、夜市、商业街** | 1. 场地租赁合同或不动产权证明。2. 商户与实际经营方签订的合作协议。3. 现场场地视频。 |

## 小微商户升级执照操作指引

### 小微商户升级执照操作流程

1. **登录并查询**：代理商登录"收银通展业版APP"，点击"查询"，在"自有商户"列表中找到需要升级的小微商户。
2. **进入商户详情**：点击该商户，进入其详情页面。
3. **进入身份资料**：在商户详情页，点击"身份资料"。
4. **发起升级**：在身份资料页面，点击侧边栏的"升级"按钮。
5. **阅读提示**：仔细阅读弹出的"商户升级提示"，确认无误后点击"继续"。
6. **选择商户类型**：根据商户的营业执照，选择需要升级的商户类型（"个体工商户"或"企业"）。

   - 输入"营业执照编号"和"营业执照名称"。
   - 可点击右侧的"OCR文字识别"按钮，通过拍照自动填充信息。

    - 点击上传"营业执照"照片。

## 商户微信认证操作指引

### 商户微信认证背景与目的

微信认证，也称"商户开户意愿确认"。由于微信支付的风控要求，商户需完成开户意愿确认。未完成认证的商户，其交易将被拦截，并可能面临后续更严格的风控措施。

### 商户微信认证流程概览

认证流程主要分为以下三步：

1. **联系人**：扫描渠道商二维码，提交商家资料完成注册。
2. **法人**：授权联系人的微信，以绑定商家资料。
3. **联系人**：使用微信授权门店商户号。

**操作路径**：登录收银通展业APP → 我的 → 微信实名认证 → 找到对应商户详情页面 → 将认证二维码发给商户扫码授权。

### 小微商户微信认证步骤

1. 法人使用本人实名认证的微信，扫描商户所属的渠道二维码。
2. 扫码后，点击"关注"，关注"微信支付商家助手"微信公众号。
3. 进入公众号，公众号会推送一条"开户意愿确认通知"消息。
4. 点击该推送消息，核对商户号信息。
5. 核对无误后，勾选商户信息，点击"确认无误"。
6. 页面跳转至"确认成功"，即表示商户已开通支付权限，可以正常交易。

### 有营业执照及其他类型商户微信认证步骤

1. 点击商户类型，根据实际情况选择商户主体类型。
2. 填写联系信息以及商户资料。
3. 使用已选定的联系人微信，扫描商户所属的渠道二维码。
4. 点击确认，进入资料上传页面。
5. 上传营业执照、法人身份证正反面照片，并核对信息。
6. 上传完毕后，提交系统审核（约20秒）。
7. 审核通过后，页面会自动跳转至身份验证环节。
8. 请联系法人使用其本人实名认证的微信，扫描联系人分享的二维码。
9. 法人扫码后，点击确认商户号，完成授权。
10. 页面跳转至"确认成功"，即表示商户已开通支付权限，可以正常交易。

### 微信认证对公打款认证授权路径

- **适用范围**：仅支持企业和其他组织，**个体户暂不支持**。
- **操作流程**：商户扫描渠道码并填写完基础信息后，页面会显示对公打款入口。商户需使用指定户名的银行账户，向财付通指定银行账户汇款指定金额，以完成验证（汇款有效期为10天）。

## 商户支付宝认证操作指引

### 商户支付宝认证背景与目的

商户在乐刷收银通系统成功入网后，需进行支付宝子商户号的授权关联。未完成此步骤的商户，其支付宝收款功能将被限制，导致无法正常交易。

### 商户支付宝认证流程概览

支付宝认证主要包含三个核心步骤：

1. **联系人**：扫描渠道商二维码，提交商家资料完成注册。
2. **法人**：授权联系人，以绑定商家资料。
3. **联系人**：使用支付宝授权门店商户号。

**操作路径**：代理商登录收银通展业APP → 我的 → 支付宝实名认证 → 找到对应商户详情页面 → 将渠道二维码发给商户法人扫码认证。

### 支付宝认证方式一信息确认二维码认证流程

此方式适用于代理商协助商户完成认证。

1. **代理商操作**：
   - 登录收银通展业APP，进入"查询" -> "自有商户"。
   - 点击目标商户进入详情页，找到"支付宝交易信息"模块。
   - 点击"去授权"，将生成的二维码截图发送给商户法人。
2. **商户法人操作**：
   - 使用**本人实名认证的支付宝**扫描代理商提供的二维码。
   - 点击"去核实收款账号"。
   - 在列表中勾选正确的收款账号，点击"确认"。
   - 页面提示"收款账号绑定成功"后，即可开始收款。

### 支付宝认证方式二商家自行认证流程

此方式适用于商户法人自行完成全部认证流程。

1. **核实商家身份**：
   - 商户法人扫描渠道商拓展二维码，进入支付宝小程序。
   - 选择商家主体类型（若已核实可跳过）。
   - 填写联系人信息，并上传营业执照、法人/经营者身份证照片。
   - 提交资料，等待支付宝系统审核。
2. **法人信息确认**：
   - 联系人提交资料后，需联系法人进行信息确认。
   - **方式1：法人扫码授权**：法人使用本人实名认证的支付宝，扫描"信息确认二维码"。
   - **方式2：点击消息授权**：法人可在支付宝首页的消息盒子中查看并授权。
   - **方式3：对公账户打款授权**：商户使用对公账户向支付宝指定账户汇入指定金额（0.1元~1元），支付宝将在T+1日内原路退回。汇款完成2小时后可查询认证结果。
3. **核实收款账号**：
   - 法人确认信息后，联系人重新扫描认证二维码，或在支付宝搜索"支付宝商家认证助手"进入。
   - 点击"去核实"。
   - 在列表中选择当前服务商名下的收款账号，点击"确认"即可完成授权。
   - 若列表中无收款账号，可点击"手动添加"进行搜索和添加。

### 商户支付宝认证状态说明

在新商户进件后，乐刷系统会自动为商户向支付宝进行上报。上报后需等待支付宝侧系统审核。在此期间，点击"去授权"可能会出现不同提示，请根据系统操作建议进行处理。

## 商户收单协议签署操作指引

### 商户收单协议签署路径

商户可通过以下两种路径进入协议签署页面：

1. **弹窗签署**：登录"收银通APP"后，若协议未签署，系统会自动弹出签署提醒。
2. **手动进入**：登录"收银通APP" → 我的 → 商户信息 → 签约费率 → 特约商户支付合作协议 → 续签。

未签署协议的商户，其交易额度或交易功能可能会受到影响。

### 小微及个体工商户收单协议签署流程

1. **进入签署**：点击弹窗中的"去签署"或在"签约费率"页面点击"去签约"。
2. **浏览协议**：进入协议浏览页面，仔细阅读协议内容。
3. **手写签名**：
   - 点击页面下方的签名处，进入"手写签名"页面。
   - 根据提示，将手机横屏，在签名区使用正楷字体书写姓名。
   - 可点击"撤销重签"清空已写签名。
4. **签名检测**：
   - 签名完成后，系统会自动进行签名检测。
   - 若检测不通过，需重新签署。
   - 若检测通过，点击"签署完成"按钮。
5. **签署成功**：页面提示"签署成功"，即完成协议签署。

### 企业商户收单协议签署流程

企业商户的签署流程更为严格，需经过法人授权和人脸识别认证。

#### 企业商户签署管理员身份选择

登录APP后，需选择本次发起签署的管理员身份：

- **企业法定代表人**
- **企业授权代理人**

#### 企业商户签署企业认证流程

| 管理员身份 | 认证操作步骤 |
| :--- | :--- |
| **企业法定代表人** | 1. 上传营业执照并填写企业信息。2. 认证方式选择"法人身份认证"。3. 系统将向法人手机号发送授权协议，法人需同意并进行人脸识别。 |
| **企业授权代理人** | 1. 上传营业执照并填写企业信息。2. 认证方式选择"法人授权认证"。3. 输入法人手机号，系统将向法人手机号发送授权协议，法人需同意并进行人脸识别。 |

**特别注意**：目前仅支持持有中国大陆居民身份证的法人代表进行授权认证。

#### 企业商户签署协议签署流程

1. 法人完成人脸识别认证后，会通过短信接收到一份授权协议。
2. 法人根据短信指引，输入验证码完成协议签署。
3. 页面提示"签章成功"，即表示企业商户协议签署完成。

## 个体工商户非法人电子签章操作指引

### 个体工商户非法人电子签章功能背景与规则

#### 功能背景

对于选择非法人结算的商户，传统方式需要上传纸质版的结算授权函照片。此功能上线后，个体工商户可以通过签署电子协议的方式完成授权，更加便捷。

#### 功能规则

1. **适用商户**：仅支持**个体工商户**类型（大陆身份证）。
2. **操作渠道**：仅支持通过**收银通展业APP**操作，需将APP升级至2.1.9或以上版本。
3. **使用次数**：每个展业人员（代理商/业务员）账户，每月支持生成**10份**电子协议。
4. **适用场景**：支持用于非法人结算商户的**入网**、**修改同名结算卡**以及**更换结算人**。
5. **协议时效**：生成的电子协议链接，需在**72小时内**由法人完成签署，超时将自动作废。

### 个体工商户入网非法人结算电子签章流程

此流程适用于总店商户的入网申请。

1. **选择授权方式**：在展业APP入网流程中，结算方式选择"打款至指定银行账号"后，在授权方式处选择"方式二-新协议-生成新协议"。
2. **核对并生成协议**：系统会展示商户信息和结算信息，核对无误后，点击"生成协议"。
3. **发送签约链接**：协议生成后，点击"复制链接"，将链接发送给商户法人。
4. **法人签署流程**：
   - 法人点击链接，填写姓名、身份证号、手机号并获取验证码。
   - 进行人脸识别验证。
   - 核对《结算账户确认书》信息，确认无误后输入验证码，完成电子签署。

### 个体工商户分店入网非法人结算电子签章流程

分店入网时，根据资料是否与总店一致，分为两种情况：

- **情况一：分店资料与总店不同**
  操作流程与总店商户入网流程完全一致，需为分店单独生成并签署新的电子协议。
- **情况二：分店资料与总店一致**
  1. 在入网资料页面，选择"与总店资料一致"。
  2. 如果总店当初是通过**纸质授权**（方式一），系统会自动将总店的授权文件同步到分店。
  3. 如果总店当初是通过**电子协议**（方式二），则需要代理商在分店入网时，手动录入法人身份证等信息，并**选择总店已签署的电子协议**。

### 个体工商户修改非法人同名结算卡电子签章流程

当商户需要更换为另一张同名银行卡时，代理商可通过展业APP协助操作。

1. 在修改结算卡信息时，可选择结算授权方式。
2. 若选择电子协议签署，可以重新选择已有的协议或生成新的协议。
3. 生成新协议会消耗当月的协议生成次数。

### 个体工商户更换非法人结算人电子签章流程

当商户需要将结算人从"非法人A"更换为"非法人B"时，仅支持通过法人签署电子协议的方式进行更改。

1. 代理商在展业APP端发起更换结算人操作。
2. 系统会生成一份新的电子协议，需由法人重新签署授权。
3. 生成新协议会消耗当月的协议生成次数。

### 个体工商户非法人电子签章协议状态说明

在上传授权证明时，可能会遇到以下三种协议状态：

| 协议状态 | 签署状态 | 操作指引 |
| :--- | :--- | :--- |
| **正常** | **未签署** | 可复制链接发送给法人，让其完成电子签约授权。 |
| **已作废** | **未签署** | 协议已过期，需重新生成一份新协议，并提供新链接给法人签约。 |
| **正常** | **签署成功** | 授权已完成，可直接上传该协议，继续完成商户入网流程。 |

## 商户入网常见问题解答

### 问：小微商户支持增加入网次数吗？

答：小微商户暂不允许申请增加入网次数，如有特殊场景请联系运营并描述具体场景。

### 问：微信认证时，商户号信息未显示怎么办？

答：在最后一步"确认商户号"时，若系统不显示商户号信息，可点击"点击搜索"，在搜索栏中输入"微信商户号"（可在展业版APP的"我的-商户微信实名"中查看），然后点击"搜索"即可完成认证。

### 问：微信认证时提示"商户号达到上限"怎么办？

答：同一个小微商户给同一个渠道商账号最多授权1个商户号。若已达到上限，可选择任意一个目前无需关联的商户，点击"取消关联"，然后重新对目标商户进行"确认商户号信息"操作即可。

### 问：微信认证时提示"你不是该商户的管理员，不可以解绑该商户号"怎么办？

答：商户号只能由最初的"授权人"进行解绑，同主体下的其他管理员无法操作。

### 问：商户注册微信认证时提示"重复注册"怎么办？

答：该提示说明该主体已完成过商家注册，无需重复提交。

1. 让商户进入"微信支付商家注册"小程序，在"我的商家"页面查看是否有对应主体信息。
2. 若有，则直接扫描"渠道商二维码"完成商户号授权即可。
3. 若无，则申请撤销当前申请单，再重新扫描"渠道商二维码"进行认证。

### 问：新注册的营业执照微信认证时需要手动填写信息？

答：新增的营业执照信息同步需要时间，建议在注册5-10天后再提交认证。若急需认证，可尝试重新上传资料，并手动输入商户名称、注册号和法人身份证信息后提交。

### 问：微信认证时提示"你的商家资料异常，请重新进行注册"怎么办？

答：此提示通常是因为创建申请单的管理员与进行法人授权的微信不是同一人。解决方法是：必须由最初创建申请单的管理员（即提交申请单的微信号）扫描渠道二维码来授权商户号。

### 问：微信认证时提示"商户资质存在风险，暂不支持绑定"怎么办？

答：该商户因历史经营中违反了微信支付服务协议，暂不支持授权绑定。请留意后续开放情况。
