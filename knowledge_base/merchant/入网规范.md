
# 乐刷收银通商户入网资料规范

本规范旨在指导代理商高效、准确地完成商户入网（进件）资料的准备与提交，避免因资料问题导致的审核驳回。

## 商户入网通用规范

### 禁止入网地区与主体限制
*   **禁止入网地区**：西藏自治区。
*   **主体限制**：
    1.  已注册为一级代理商的营业执照，不得再作为特约商户提交入网申请。
    2.  已入网成功的乐刷商户，其营业执照不可再用于申请一级代理商资格。

### 行业限制与特殊要求
*   **禁入行业**：房地产、保险、投资、融资、投融资、广告、棋牌类、基金、理财、套现、信用卡、传销等。
*   **黄金珠宝行业**：
    *   需营业执照入网且对公结算，经营范围须包含黄金、珠宝等。
    *   若非对公结算，默认关闭T0结算权限，并需提供包含法人、业务员、门店环境、终端SN码及实时定位的经营场景视频。
*   **汽车行业**（含汽车销售、二手车、租赁、车贷等）：
    *   仅支持个体户或企业商户入网，不支持小微商户。
    *   福建地区商户需额外上传对应许可证，并在入网后提交实地巡检视频。
*   **投资行业**：除营业执照外，还需提供经营许可证。
*   **结算限制**：新疆地区不支持企业非法人对私结算。

### 小微商户特别规定
*   **名称规范**：小微商户的法定名称不应设为“广场”、“中心”、“KTV”、“酒店”、“商场”等与实际经营资质不符的名称。
*   **MCC规范**：小微商户入网的MCC不应为“住宅开发”、“铁路货运”、“烟草配送”、“公共事业”等与实际经营资质不符的类别。
*   **禁入行业**：小微商户不支持“珠宝黄金”、“汽车销售”、“二手车销售”、“汽车租赁”、“车贷”、“车行”、“货车”、“房地产”、“保险”、“投资”、“融资”、“投融资”、“旅行社”、“养老”、“殡仪”、“公司”、“玉石”、“棋牌室”等行业入网。

## 特殊场景进件规范

### 停车场商户
*   **商户简称**：必须包含“停车场”或有停车含义的字眼。
*   **三合照**：拍摄需包含停车杆和车场照片。

### 食堂/餐厅商户
*   **资料复用**：同一个食堂的多个档口可使用同一套营业执照和三合照进件。
*   **门头照**：拍摄连排档口照片。
*   **商户简称**：可使用主体执照名称或各档口实际名称（如“xx学校食堂档口1”）。

### 酒吧
*   大型酒吧、夜场等，允许同一证件使用同套资料注册多个商户编号，三合照需能体现是大型酒吧或夜场。

### 出租车
*   **商户简称**：使用车牌号，不得套用知名品牌名称（如滴滴、神州专车）。
*   **三合照**：只需提供一张商户本人与车辆的合影，需清晰看见车头、车牌和商户本人。

### 彩票类商户
*   **小微商户**：在其他图片中上传彩票代销证。商户全称填“商户_XXX”，简称填“体育彩票+门店编号”。
*   **个体/企业**：需有对应营业执照，并上传彩票代销证。商户全称填营业执照全称，简称填“体育彩票+门店编号”。
*   **注意**：若三合照中包含体彩、福彩标识，必须提供代销证。

## 图片资料提交通用规范

### 身份证图片
1.  必须为真实拍摄的原件照片，禁止隔屏拍摄、截图或PS。
2.  照片需露出身份证四个角，信息清晰无反光。
3.  身份证正反面照片的拍摄背景需一致。
4.  身份证超过有效期或即将在1个月内过期的，不能入网。
5.  如上传复印件，需加盖公章，且公章不能遮挡关键信息。

### 营业执照图片
1.  必须为真实拍摄的照片，禁止截图、PS或含有水印。
2.  照片需露出营业执照四个角。
3.  如上传复印件，需加盖公章，无公章视为无效。
4.  **小微商户无需上传营业执照图片，切勿用其他图片代替。**

### 店铺环境图片（三合照）
1.  必须为真实线下场景拍摄，禁止使用网图、PS、截图或含有水印、边框。
2.  必须上传门头照、店内照、收银台照三张不同照片（停车场除外）。
3.  连锁店需上传本店三合照，不可重复使用其他店铺的照片。
4.  无实体店铺的流动摊位，可拍摄体现门店招牌、经营内容、收银场景的照片。

### 银行卡图片
1.  必须为真实拍摄的银行卡照片，禁止截图、PS或含有水印。
2.  照片需露出银行卡四个角。
3.  **对公结算**：上传开户许可证或银行印鉴卡。
4.  **对私结算**：上传有卡号一面的银行卡照片。若卡号磨损，可将卡号写在纸上与银行卡一同拍摄。
5.  **三要素鉴权失败处理**（4选1）：
    *   核实并修改结算卡信息。
    *   更换一张结算卡。
    *   上传近一周的转账成功截图（体现开户名和卡号）至其他资料栏。
    *   上传银行提供的商户流水（体现开户名和卡号）至其他资料栏。

### 非法人结算授权书
1.  使用乐刷提供的《结算账户确认书》模板。
2.  按要求填写完整信息，包括商户名称、法人信息、被授权人信息等。
3.  企业需加盖公章，并由法人代表/授权人签字和按手印。
4.  个体工商户由经营者签字和按手印。
5.  将法人身份证原件照片按格式放置在授权书上拍照上传。

## 港澳台等证件入网说明

### 进件标准
*   支持港澳台通行证、香港/澳门/台湾身份证、护照、居住证等法定证件。
*   商户主体必须是在中国大陆注册的个体户或企业，**暂不支持小微商户**。
*   经营地址必须在中国大陆境内。
*   结算类型仅支持对私法人结算或对公法人结算。

### 进件流程
1.  商户类型选择“个体户”或“企业”。
2.  法人证件类型选择对应的证件（如“港澳台通行证”）。
3.  收款账号填写在中国大陆开立的银行账户。
4.  **特别注意**：港澳台通行证入网时，证件号处需填写“证件号码+换证次数”（例如证件号为`123456`，换证次数为`01`，则填写`12345601`）。

### 特别说明
*   使用其他证件类型入网的商户，审核通过后不允许修改法人信息。如需变更，请重新进件。
